# 國中畢業後出路比例（民國80-89年出生，約95-104學年入高中職）
- 高一新生 普通高中:高職 = 44:56（99學年，綜合高中計入高中）；107學年變成 49:51。來源：立法院預算評估報告 https://www.ly.gov.tw/Pages/Detail.aspx?nodeid=33363&pid=185018
- 職業類（含綜高專門學程、五專前三年）:普通類 ≈ 5.5:4.5（102學年）。來源：教育部《技術及職業教育》2014手冊
- 高職應屆畢業生：升學率 99學年 79.6% → 105學年 72.2%；就業率 13.9% → 20.0%。高中應屆畢業生升學率約 95-96%。來源同立法院報告附表3-20
- 更早：高職升學率 91學年 56.0% → 94學年 69.8%（教育部統計處 https://stats.moe.gov.tw/files/analysis/highv_graduate.pdf）
