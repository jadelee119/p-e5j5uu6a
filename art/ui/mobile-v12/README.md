## 1. 現況：為什麼要捲動（實測）

線上 v1.1，視窗 390×844（375×667 的結果幾乎一樣，因為版面只依寬度排）：

| 元素 | 高度（CSS px） | 說明 |
|---|---|---|
| 標題卡：「人生手牌・國中・臺北市」＋六條屬性條（兩欄三列，有等級字） | 159（y 24–183） | 屬性條在 <480px 寬時排成兩欄，佔了三列 |
| 結果卡（打出一張牌後才出現）：拍立得插圖＋「你打出了…」＋結果文字 | 376（拍立得本身 255） | 每打一張牌就把手牌往下推 |
| 「今年的時間」標題＋時間圓點 | 約 61 | |
| 手牌：`.hand` 用 `minmax(140px,1fr)` 排成兩欄 | 5 張牌 717；打掉一張後剩 4 張還有 500 | 每張牌 226–245 高：4:3 圖約 102 高，加上名字、兩到三行說明、時間圓點 |
| 「今年做了：…」＋「過完今年」按鈕 | 約 49＋60 | |
| **整頁** | **開局 1115；打出一張之後 1329** | 螢幕可視高度 844（扣掉安全區約 763）→ 要捲 1.5 到 1.7 個畫面 |

主因：
1. **手牌兩欄直排**，5 張牌就要三列，光手牌就 717px。
2. **牌面放了全文**（說明句兩到三行），每張牌高 226–245。
3. **結果卡插在手牌上面**，每打一張牌就把手牌和按鈕推出畫面，最常按的「過完今年」永遠在畫面外。
4. 屬性條在窄螢幕排成三列，加上等級字，佔了 159px。
5. 另外：所有牌的外框都是同一個紅色（`--color-accent`），沒有用到每張牌自己的 accent。

## 2. 共用規則（兩案都適用）

- **數字規則**（QA 定案 Q11，見 `design/v1.2-spec.md` 通用規則）：禁用阿拉伯數字（含全形），也禁用會透露屬性、年份、年齡、金額、分數或名次的字，就算用國字寫也一樣（例如「考了四百分」「全班第一名」）。日常量詞可以，例如「下課十分鐘」「排到第三輪」「一盒蠟筆」「一下午」「國二」。美術的做法：
  - 圖裡不放任何可讀的數字或文字。
  - 時間格＝手繪時鐘，鐘面沒有刻度數字；用掉的畫成灰色虛線再打叉。
  - 牌的時間成本＝牌右下角的小時鐘，用個數表示。
  - 會過期＝牌左下角的小沙漏，不寫幾歲。
  - 屬性＝圖示加五格蠟筆條，主畫面不放等級字，點整條才打開屬性詳情（沿用 stat-bars 的等級字）。危險的屬性用紅色虛線圈起來。
  - 包袱背了多久＝引信。
- **階段和學期**：左上黑板色的牌子。
  - 階段字：國中、高中、大學、出社會。
  - 年份圓點：三個圓，走過的年塗白。
  - 學期：兩本小課本。上學期亮左邊那本；下學期兩本都亮，並加一條紅書籤。旁邊寫「上學期」或「下學期」，這兩個詞不是數字。
  - **出社會路線：上半年／下半年**（spec §3.1、場景 `sc_half_first`／`sc_half_second`）。課本換成兩張撕頁月曆（12×15，同位置同尺寸，頁面空白、不寫月份或日期）：上半年亮左邊那張；下半年兩張都亮，第二張上緣加一個紅色圖釘。旁邊寫「上半年」或「下半年」。黑板牌的階段字寫「出社會」，年份圓點照舊。
  - **沒有暑假的情況**（QA 定案 Q4）：22 歲沒有暑假，出社會路線也沒有暑假事件（只有寒假的「過年」）。所以這兩種情況下，回合之間不出現暑假過場的圖（例如西瓜、電風扇），也不顯示暑假的標籤；排在暑假槽位的時代牌在「下半年」回合結束時用舊電視框翻開。
- **主色**：每張牌用自己的 `accent`（cards.json），只用在外框、名字底下的蠟筆線、選取時的光暈和詳情底板的主按鈕，不整張塗滿，所以每張牌都有自己的顏色，不會全是黃色或褪色。
- **風格**：手繪抖動線（SVG 用 feDisplacementMap 做示意，正式版建議用 `border-image` 或預先畫好的 9-slice 框），紙紋，拍立得加膠帶，牌微微歪斜（±2 到 5 度），不要排成死板的投影片格子。
- **點擊區域**：所有可點的東西至少 44×44。扇形裡露出來的寬度也至少 44（見 §5 的公式）。
- **安全區**：上方用 `env(safe-area-inset-top)`（390×844 的瀏海約 47），下方用 `env(safe-area-inset-bottom)`（Home 指示條約 34）；375×667 上方 20，下方 0。mockup 裡用灰色斜線標出來。
- **包袱每學期痛一次**：那張牌晃一下（mockup 用牌旁的抖動線表示），舞台上貼一張便條旁白，例如「『家裡的帳單』又晃了一下。」（正式旁白等文案）。

## 3. 方案 A：扇形手牌＋底部詳情（推薦）

手牌在畫面最下方排成扇形，牌只放圖和名字。點一下牌，從下方滑出詳情底板，在底板上才看到全文和「就做這個」。

### 區塊尺寸（CSS px）

| 區塊 | 390×844 | 375×667 |
|---|---|---|
| 上安全區 | 0–47 | 0–20 |
| 頂列（階段牌＋縣市＋選單鈕 44×44） | 49–93（44） | 22–66（44） |
| 屬性列（6 格圖示＋五格條） | 97–139（42） | 70–108（38） |
| 舞台（拍立得＋結果文字＋包袱便條；會伸縮） | 141–546（約 405；拍立得 300 寬、圖 180 高） | 110–423（約 313；拍立得 230 寬、圖 128 高） |
| 時間列（時鐘＋「做了：」印章） | 550–580（30） | 427–457（30） |
| 手牌（標籤＋扇形，含旋轉和下沉） | 584–744（約 160） | 461–601（約 140） |
| 「過完這學期」按鈕 | 750–802（52） | 607–659（52） |
| 下安全區 | 810–844 | 659–667（只留 8px 邊距） |

- 手牌：390 用 88×128，5 張時每張露出 65.5px；375 用 74×108。驗收張數是 6 張（5 張含包袱和強制牌，加 1 張臨時牌；QA 定案 Q10），每張露出約 52px。375 仍以 7 張設計，當作安全邊際：7 張時每張露出 44.8px，仍然 ≥44。7 張不是規則上限。時代牌用舊電視框在舞台翻開，不進手牌。
- 詳情底板：最大高度 390 是 74%（624px），375 是 86%（574px）。上方是大圖（390 用 16:9，342×192；375 用 2:1，327×164），接著是牌名（明體 24px，下面一條主色蠟筆線）、過期標籤、全文（粉圓 17px）、「要花的時間」（時鐘），最後是「再想想」（44 高，外框按鈕）和「就做這個」（54 高，用那張牌的主色、白字）。
- 包袱詳情底板：整片換成那個包袱的布紋深色，上緣有布耳打結。內容依序是褪色的舊照片圖、朱紅大印章、名字和全文（粉筆白），然後是大的引信和「引信燒完，就會出事。」，最後兩顆按鈕：「先背著（每學期都會痛）」和「花時間處理掉（暫時的）」，後者前面畫一個時鐘表示成本。

優點：
- 一回合要用的東西都在同一個畫面，「過完這學期」固定在拇指區。
- 舞台夠大，結果插圖和旁白不會被犧牲。
- 跟卡牌遊戲的直覺一樣，看起來像遊戲，不像表格。
- 詳情底板順便解決了「牌面放不下全文」的問題，也符合企劃「點開才看全文」的需求。
- 驗收的 6 張很寬鬆，到 7 張也排得下，包袱一眼就看得出來。

缺點：
- 牌面只有名字，要點開才知道內容，打一張牌從點一下變成點兩下（點開、確認）。不過這也符合「選了就算數」，可以減少誤觸。
- 扇形重疊時，右邊的牌會蓋到左邊那張的右半部，所以名字和印章都要靠左上放（已照這樣設計）。

工程量（美術估計，以工程師的估算為準）：中等。扇形用 flex 加負的 margin，再加上 `rotate`；詳情底板用 `<dialog>` 或固定定位的 div 加 transform 動畫；牌框可以先用 CSS border 加主色，手繪框之後再換。約 1 到 1.5 天。

## 5. 為什麼是 A（已定案）

理由：
- A 一個狀態就能打完一回合，主要按鈕的位置固定。
- 舞台（打出的結果、旁白、包袱便條）永遠看得到，這是我們「心酸又溫柔」的文字要待的地方。
- 驗收的 6 張在 375 每張露出約 52px；到 7 張（安全邊際）也守得住 44px 的點擊寬度。
- 工程量比 B 小。

**扇形和捲動列**：美術 mockup 用的是扇形（所有牌一次看得到，不用橫向滑），工程灰盒用的是橫向捲動列加上固定在左邊的包袱區（`.pinned`）。兩種都算 A，`skin.css` 也都支援：
- 灰盒的 `.handrow` 預設就是捲動列。
- 加上 `class="handrow fan"`，每張牌再設 `style="--i:<index>;--n:<count>"`，就會變成扇形。

美術建議先上扇形：驗收的 6 張在 375 寬每張露出約 52px，到 7 張也還有 44.8px。萬一手牌超過 7 張（7 張不是規則上限，只是版面的安全邊際），自動退回捲動列。

### 橫向／PC（Steam 為主）

- **A**：舞台放在左邊約 60%，右邊一欄放屬性條（這時可以顯示等級字）。手牌扇形放在下方置中，牌放大成 132×192。詳情底板改成從右側滑出的側板（寬 420），或置中的對話框，不蓋住手牌。滑鼠移到牌上時把牌抬高 14px，加上主色光暈。
- 手機橫放：建議鎖成直式；如果不鎖，就用 PC 的排法，但牌縮成 88×128。

## 6. 牌面規格（給工程師的灰盒直接套）

### 一般手牌（action、growth、forced）
- 尺寸：`--hand-card-w` × `--hand-card-h`。390 以上用 88×128，375 以下用 74×108，PC 用 132×192。
- 圓角 7px，底色 `--card`，外框 2.6px 用 `var(--acc)`。
- 圖窗：內距 5px，寬＝卡寬−10，高＝(卡寬−10)×0.72（約 7:5）。`object-fit: cover; object-position: 50% 50%`。原圖是 1280×720，主體大多在正中間，左右各放大 12% 也不會切到主角。
- 名字：粉圓 13px（5 字以上用 12px），粗體，最多兩行，靠左上，下面一條 3px 主色蠟筆線（透明度 .55）。
- 右下角：成本時鐘，每個 10.4px，用主色。左下角：沙漏表示會過期。
- 牌面不放說明句，說明只出現在詳情底板。
- growth：沿用現在的雙線外框。forced：外框加粗，但仍然用自己的主色（不要全部改成紅色）。

### 包袱牌（burden，sticky）
- 跟一般牌同尺寸，佔一個手牌位置，但視覺重量加倍：
  - 底色：`color-mix(in srgb, var(--acc) 55%, black)`，疊一層布紋（斜 45 度格線加小點，白色透明度約 .1）。
  - 深邊：`color-mix(in srgb, var(--acc) 32%, black)`，粗 4.5px；內側一圈粉筆白虛線縫線（1.2px，虛線 4/3）。
  - 布耳打結：凸出牌頂約 14px，可以用一張共用的 SVG 再上色。
  - 圖窗套舊照片色：`filter: sepia(.6) saturate(.5)`。
  - 朱紅「包袱」印章：26×18，放左上角，斜 −12 度，這樣在扇形裡也不會被下一張蓋住。
  - 名字用粉筆白 `--color-chalk`。
  - 陰影比較重：`0 6px 8px #1d191566`。在扇形裡往下沉 6px。
- **引信（背了多久）**：放在牌的下緣，段數＝`trigger_after`，每段是一小截繩子加一個結。已經背過的學期燒成焦黑虛線，目前的位置畫火星，燒完就觸發 `trigger_card`。不寫數字，引信越短越危險。
- 每學期觸發懲罰時，牌晃一下（`@keyframes` 左右各 3 度，約 300ms），再出一句便條旁白。
- 最多 2 張包袱同時留在手上。超過時，最舊那張的引信會一口氣燒完、晃一下，然後離開。

### 時間格、學期、幕次
- 時間格：手繪時鐘，直徑 18px，間距 26px。可用＝膠帶黃底加黑板綠線；用掉＝灰色虛線加一道斜線。
- 學期：兩本 12×15 的小課本，下學期在第二本加紅書籤。
- 童年序章的幕次：右上三個圓點，依序是「剛上小學」「小學中年級」「小學快畢業」（QA 定案 Q16），不寫「第幾幕」。第一幕「剛上小學」也涵蓋上小學前那一年，名稱不變。

### 童年序章三選一（記憶牌）
劇情文案的規格是：選之前就要看到牌名、處境和後果；每一幕的三張牌來自三個不同類別。所以記憶牌改成**橫式長卡，三張直排**，跟灰盒的 `.mem` 結構一樣：

| | 390×844 | 375×667 |
|---|---|---|
| 卡片 | 366×150，間距 16 | 351×124，間距 10 |
| 圖窗（左） | 寬 84 | 寬 72 |
| 三張的範圍 | y 183–679 | y 132–536 |
| 「就是這個」按鈕 | 746–800 | 603–657 |

- 牌面由上到下：
  - **類別小圓章**：22px 的圓，裡面放圖示（讀書＝書本、玩樂＝風箏、運動＝腳踏車、才藝＝音符、顧家＝店面遮雨棚），不寫數字也不寫字。後面接**牌名**（明體 16px，375 用 15px）。
  - **處境**：黑體 13px，最多兩行。
  - **一條主色虛線分隔**。
  - **後果**：粉圓 12px，顏色是灰褐色混一點類別色，前面加一個手繪的「↳」小箭頭，最多兩行。字比較小、比較淡，一看就知道是「選了會怎樣」，不會跟處境搶。
- 圖窗下方寫「＋讀書」，表示會洗進牌庫的那張牌（效果直接看得到，回應「天賦摸不著頭緒」）。
- 記憶牌還沒有插圖（三十張都沒有），先用**類別主色的佔位圖框**：淡色斜線底、主色虛線框、一個空白臉的小人剪影，加上「插圖待補」。

## 8. `skin.css`（給工程直接套用）

- 位置：`art/ui/mobile-v12/skin.css`。載入在灰盒 `common.css`（或正式的 `style.css`）之後。它只改外觀，不改版面流程，類別名稱跟灰盒對齊：`.mini`、`.is-burden`、`.badge`、`.pinned`、`.handrow`、`.sheet`、`.resbar`、`.meter`、`.slots`、`.mem`、`.btn.primary`、`.toast`。
- 套在灰盒上的實際效果見 `skin-preview-A-turn`、`skin-preview-A-burden`、`skin-preview-C`（都是 375×667）。灰盒只有灰色佔位圖，所以截圖裡沒有牌圖。
- 工程要在標記上補的東西：
  1. 每張牌設主色：`<button class="mini" style="--acc:#C25A80">`（值取 cards.json 的 `accent`）。沒設的話會退回紅磚色，所有牌又會變成同一個顏色。詳情底板也一樣：`<div class="sheet" style="--acc:…">`。
  2. 包袱的詳情底板加 `class="sheet is-burden"`，整片就會換成包袱巾。
  3. 引信：在包袱牌和包袱詳情裡放 `<span class="fuse" style="--fuse-total:4;--fuse-burnt:3"></span>`。段數用 `trigger_after`，已燒段數用連續背著的回合數。這兩個值只是 CSS 變數，畫面上不會出現數字。
     - **改名（2026-10-17）**：原本 `skin.css` 的 `:root` 也有一個 `--fuse-burnt`，拿來放「燒過那段的顏色」，跟元素上的「已燒段數」同名。工程在元素上一設段數，顏色就被蓋成數字，整條引信的 `background` 失效，所以工程在 `deck-mobile.css` 用固定色重畫了一次。顏色變數已改名為 **`--burden-fuse-burnt`**，`--fuse-burnt` 只留給段數，工程的標記不用改，`deck-mobile.css` 那段固定色的補丁可以拿掉。其他 `skin.css` 變數都對過工程的 CSS（`game/src/*.css`、`deck-ui.ts` 的行內樣式、灰盒 `common.css`），同名的都是刻意覆蓋同一個意思的主題值（例如 `--color-bg`、`--topbar-h`），沒有其他撞名。
  4. 學期：`<span class="sem" data-sem="1"><i></i><i></i></span>`，下學期把 `data-sem` 設成 `2`。
  5. 記憶牌：`<button class="mem" data-cat="study">`，牌名前加 `<i class="cat"></i>`，後果放 `<span class="cons">`。
  6. 序章進度圓點建議加 `class="slots prog"`。一般的 `.slots` 會被換成時鐘；灰盒的 `#prog` 已經先處理好。
  7. 扇形（可選）：`class="handrow fan"`，每張牌設 `style="--i:0;--n:7"`。
- 包袱晃動沿用灰盒的 `.shake`，換成左右擺動 3 度；系統設定減少動態效果（`prefers-reduced-motion`）時關掉。
- 字型：`--font-hand` 要先有 `@font-face`（正式遊戲的 `fonts.css` 已經有）。
