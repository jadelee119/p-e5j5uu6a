# v1.2 規格文字（劇情文案）

對照 `design/v1.2-spec.md`（a1b9fc6）。這份是規格裡指派給劇情文案的全部文字，章節順序照規格排。card id 和欄位名稱（`name`、`line`、`result_text`、`album_text`、`regret_text`、`by_age`、`by_track`）都照規格和 `data/deck/cards.json`。數值和條件一律以規格為準，這份不改數值。

- 回憶卡的處境和後果在 `writing/v1.2_childhood_memory_cards.md`（第二版），這份不重複。
- 每回合持有包袱時的旁白，我暫時取名 `held_text`，要等企劃確認欄位名。
- 文字規則：
  - 不出現阿拉伯數字，也不寫任何讓玩家讀得出屬性、年份、金額、分數或名次的字眼，寫成國字也不行。日常的量詞和次數可以用，例如一下午、好幾次、國二。
  - 提到別人時一律不用第三人稱代名詞。不用 LINE。寫備審資料，不寫學習歷程。
  - 不預設爸媽都在，一律寫「大人」「家裡」。未滿十八歲的打工只寫白天的班。
  - 牌面上的 `name` 盡量十個字以內，`line` 大約三十字以內。

## 回覆企劃的兩個問題

**(a) 國中畢旅放國二下：可以。** 各校的國中畢旅在國二下到國三上之間都有，放國二下合理。建議 `d_trip` 跟著改：`age_min`、`age_max` 都改成 14，只在下學期出現，跟 `sc_school_trip` 同一回合。場景負責開場，`d_trip` 是要不要花時間格去玩。這樣國三那年可以專心寫模擬考和畢業典禮。`d_trip` 現有的文字不用改。

**(b) 出生年版本：只在年代明顯改變畫面時才做。**
- **「第一次去網咖」（mem_12_play_b）做一個版本。** 八十八、八十九年次的人十二歲時，線上遊戲多半已經在家裡的電腦上玩，不一定要去網咖。下面附上這一版的文字。
- **「直排輪」（mem_12_exercise_b）、「私中入學考」（mem_12_study_a）不做版本**。數據研究員第七輪（6c0dab3）已查：私中約每十個國一生一個，直排輪 1996–1998 最熱、2000 年代國小仍有社團，牌面維持。
- 其餘二十七張回憶卡的畫面，在整個八十到八十九年次都說得通，不做版本。

## §3.2 和 §4.2 固定場景（`data/deck/scenes.json`：name、text、by_track）

場景 id 沿用規格裡出現過的 `sc_school_start`、`sc_midterm`、`sc_sports_day`、`sc_school_trip`、`sc_graduation`。下面這五個是我暫取的，請企劃確認：`sc_mock_exam`、`sc_final`、`sc_new_job`、`sc_half_first`、`sc_half_second`。

### sc_school_start 開學
- 國中（default）：新制服大一號，大人說「會長高的」。新教室裡，你誰都不認識。
- by_track.hs_general：走進高中校門，你發現大家都跟你一樣，假裝自己不緊張。
- by_track.hs_vocational：實習工廠有一股特別的味道，學長說聞久了就會喜歡。
- by_track.hs_5yr：同屆的人要一起念五年，你看著校門，覺得前面的路好長。
- by_track.uni：迎新的學長姐很熱情，熱情到你開始懷疑有什麼目的。
- by_track.uni_tech：第一天就拿到一張器材清單，比課表還長。

### sc_new_job 新工作（出社會，19 上半年）
- 第一天上班，你把同事的名字偷偷記在便條紙上，下班前全背起來了。

### sc_midterm 段考（預設場景，放進 t_exam_cram）
- 國高中（default）：段考週到了，大家走路都在背書，福利社排隊也安安靜靜。
- by_track.uni：期中考週到了，共筆在群組裡傳得比八卦還快。
- by_track.uni_tech：期中考週，學長姐的考古題在影印店印到機器發燙。
- by_track.hs_5yr + by_age [19, 20]（五專四、五年級；21 歲後繼續念的人學程是科大，看 uni_tech 版）：期中考週，比考試更可怕的是專題進度，組員已讀不回。
- 五專一到三年級段考變體（QA v12 r3 Q4，企劃 10/17 核可）：
  - by_track.hs_5yr + by_age [16, 16]：專業科目的課本厚到可以當枕頭，段考前一晚你真的拿來睡了。
  - by_track.hs_5yr + by_age [17, 17]：段考週，影印店老闆已經認得你，順手把同學的筆記多印一份。

## 用字紀錄：「分數」（10/17，r8b Q3）

「分數」這個詞可以出現在牌面，條件是不帶任何數值，也不能讓玩家推算出分數。這是企劃和文案先前同意的，製作人 10/17 在團隊群組確認。目前用到的句子：config.json hint_under「分數差了一點，這扇門今年沒有為你打開。」，以及 endings.json ordinary_good regret_low「…可它比任何分數都難拿。」等。數字規則照舊，禁止阿拉伯數字，也禁止任何能讀出屬性、年份、金額、分數或排名的寫法。
