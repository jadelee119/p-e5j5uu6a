# 時代牌：舊電視框（美術設計）

十一張時代牌共用一個手繪舊 CRT 電視框，疊在牌圖上面。螢幕是挖空的透明區，牌圖墊在下面。外框顏色吃每張牌的 `--acc`，所以每張牌的電視顏色都不一樣。

十一張牌圖已經畫好，放在 `art/deck/era/<card id>.png`，一樣是 1280×720（見下面「時代牌牌圖」）：
`era_921`、`era_nari`、`era_sars`、`era_hsr`、`era_crisis`、`era_voucher`、`era_morakot`、`era_sunflower`、`era_flexday`、`era_covid`、`era_covid_lv3`。
重災版和序章版都共用同一張圖，主色從牌的資料帶進來。

## 外觀

- 圓角 CRT 螢幕，四邊微微鼓起，螢幕外圍一圈深色鐵框。
- 厚實的機殼（顏色＝`--acc`），上面有淡淡的木紋。右邊是控制面板，有兩顆轉鈕、喇叭格柵和一顆紅色小燈。上面有兩根小天線，下面有兩隻腳。
- 線條手繪抖動，機殼有紙紋，螢幕裡只加很淡的暗角和一道反光，不影響牌圖。
- 沒有任何文字、數字或商標。轉鈕旁邊的刻度只是短線，沒有數字。

## 怎麼用

```html
<div class="tv-box" style="--acc:#3A6FB0">
  <img class="tv-art" src="art/deck/era/era_hsr.jpg" alt="">
  <span class="tv-frame" aria-hidden="true"><!-- 內嵌 tv-frame.svg 的原始碼（Vite 用 ?raw） --></span>
</div>
```

- **SVG 一定要內嵌進 DOM**，`var(--acc)` 才拿得到牌的顏色。用 `<img src="tv-frame.svg">` 載入的話，只會顯示木頭備用色 `#8A5A3C`。
- 顏色用 `style="fill:var(--acc, #8A5A3C)"` 和 `color-mix()` 調出深淺：面板＝主色 78%、天線座和腳＝70%、鐵框＝35%（混深褐色）。舊瀏覽器不支援 `color-mix()` 的話會變黑，Steam（Chromium）和現在的手機瀏覽器都沒問題。
- SVG 裡的 id 都有 `tvf-` 前綴，同一頁內嵌好幾個也不會跟別的 SVG 撞名。重複的 id 會共用同一組濾鏡，畫出來一樣。
- 機殼外面那一圈（天線和腳的背景）是紙色，可以用 `--tv-paper` 換掉。
- 牌圖整張墊在下面（`object-fit: cover`），螢幕露出的是牌圖中間偏左上一點的範圍。

### 螢幕挖空的位置

用整張的百分比表示（`tv-frame.css` 裡的 `--tv-screen-*`）：

| | 上 | 右 | 下 | 左 |
|---|---|---|---|---|
| 螢幕外接框（含鼓起） | 16.9% | 20.8% | 7.5% | 7.0% |

- 螢幕中心大約在 (43%, 55%)。牌圖的主體請畫在 x 12%–76%、y 22%–88% 裡面，才不會被框蓋住。十一張牌圖都照這個範圍構圖。
- 如果想讓牌圖只填螢幕、不墊整張，就用 `<img class="tv-art in-screen">`，它會用上面的 inset 定位。

### 跟工程現有 `.crt` 的差別

`game/src/deck-mobile.css` 目前的 `.crt.framed .tube` 是 4:3，牌圖用 inset `12% 14% 16% 10%` 放進去。這個框是 16:9，請把 `.tube` 改成 `aspect-ratio: 16/9`，牌圖改成 `inset: 0` 鋪滿，等價寫法寫在 `tv-frame.css` 最後的註解裡。CSS 由工程改，我沒有動 `game/`。

## 時代牌牌圖

- 每張只畫一個日常生活的片刻。災害和疫情只畫生活：鐵皮教室、窗外淹水的路、一盆留著沖馬桶的水、量體溫、排隊買口罩。沒有災難現場的近景、傷者、救災畫面，也沒有任何死傷的暗示。
- 牌名是場景名，圖也不對應事件名稱。圖裡沒有文字、字母、數字、商標或真人，臉一律空白。月曆、帳單、計算機、健保卡、電視畫面都只用色塊和線條。
- **太陽花（`era_sunflower`）保持中立**：只畫一家人晚餐時電視開著，螢幕上是抽象的人群，只有一排排圓點和一條空白的跑馬燈。沒有標語、旗子、太陽花圖案或可以認出來的建築，也不表態。
- **高鐵（`era_hsr`）**：列車完全虛構，刻意避開真車的「白車身＋橘色腰帶」：車身是淺灰綠，窗戶下面有兩條細深青線（`#2E6E6A`），車頭圓圓的像玩具，窗戶是圓角小方塊，沒有標誌，**車上沒有任何橘色**。主色橘 `#D9732B` 只出現在電視框、黃昏的天空和夕陽、窗前小孩的上衣。
- 跟記憶牌同一套手繪抖線和紙紋，產生器直接 import `art/deck/memory/src/gen_memory.py` 的畫筆函式。畫的時候用 640×360 的座標，再放大兩倍，線條粗細跟記憶牌一致。
- **主色（定案）**：下表十一個顏色是製作人交給工程的**最終主色**。`data/deck/era_cards.json` 原本沒有 `accent` 欄位，由工程把這些值填進去，`manifest.json` 也記了同一組值。電視框的 `--acc` 用同一個值，所以框色和圖裡的主色會一致。在工程填好之前，`accentOf()` 會用 id 的雜湊去挑色盤，顏色會暫時對不上。圖裡跟主色綁在一起的元素已經照新色重畫，例如高鐵場景的黃昏天空和小孩上衣（列車本身不用主色）、八八的水桶和背景改成泥褐色系（水本身維持藍色）、一例一休月曆的另一種休假格改成橘色（免得跟藍色主色撞）。
- **引擎讀圖的順序**：`eraArtFiles` 抓 `art/deck/era/*.{jpg,jpeg,png,webp,svg}`，再用檔名找第一個符合的檔案。如果資料夾裡還有別人放的佔位圖（例如之前出現過的 `era_nari.jpg`），它可能會排在我的 png 前面。我沒有刪任何佔位圖，看到的話請放圖的人確認後移掉，或是讓 glob 先抓 png。
