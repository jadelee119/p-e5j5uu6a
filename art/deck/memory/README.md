# 童年記憶牌插圖（美術設計）

三十張童年序章記憶牌的插圖。id 跟 `data/deck/childhood.json` 的 `memories[].id`（也就是 `art` 欄位）一模一樣，工程的 `memArt()` 用檔名對 id，不用改程式就接得上。

## 檔案

| 檔案 | 說明 |
|---|---|
| `<id>.svg` | 向量原檔，480×600，含手繪抖線和紙紋濾鏡 |
| `<id>.png` | 遊戲用，600×750，96 色調色盤 PNG（每張約 250–300 KB） |
| `manifest.json` | id → svg／png 路徑、主色、畫了什麼；另外記比例和安全區 |
| `contact-sheet.png` | 三十張總覽，格子下面標 id（開發用，id 只出現在這張總覽上，不會出現在圖裡） |
| `crop-check.png` | 裁切檢查：每張依序裁成 84×150（390 寬的序章圖窗）、72×124（375 寬）、120×120（正方形，相簿用），都是 `object-fit: cover` |
| `src/gen_memory.py` | 產生器，三十張的構圖都在這裡；要改圖請改這支，不要手改 SVG |
| `src/render.mjs` | SVG → PNG，用 headless Chrome，再拼出 contact sheet |
| `src/pack_png.py` | 把 PNG 壓成調色盤格式 |
| `src/crop_check.py` | 產生 crop-check.png |

重新產生的步驟：
```
cd art/deck/memory/src
python3 gen_memory.py                    # 會先檢查 id 跟 childhood.json 是否一致
NODE_PATH=<裝了 puppeteer-core 的 node_modules> node render.mjs
python3 pack_png.py && python3 crop_check.py
```

## 比例和安全區

- **母版 4:5（480×600）**，主體放在正中間。
- **安全區：x 80–400、y 60–540**（中間 2:3 的框）。重要的東西都放在這個框裡，旁邊只放背景色塊和小裝飾。
- 為什麼這樣能同時用在兩個地方：
  - 序章圖窗是直的（390 寬是 84×約150，375 寬是 72×124）。用 cover 裁的時候高度整張都看得到，寬度剩中間大約 70%，也就是 x 72–408，安全區剛好在裡面。
  - 相簿或詳情如果用正方形、或 4:3 以內的框，用 cover 也一樣安全：正方形會留 y 60–540。
  - **比 4:3 更寬的框（例如 16:9 的詳情大圖）請改用 `object-fit: contain`**，旁邊的空位補紙色 `#FBFAF6`。圖的四邊本來就是紙色，色塊在中間，所以 contain 看起來會跟背景連在一起，不會看出一塊方框。
- 建議 CSS：
```css
.dk .mem img.mart { object-fit: cover; object-position: 50% 50%; }             /* 序章圖窗：直接用 */
.album img.mart   { aspect-ratio: 1; object-fit: cover; }                      /* 正方形相簿格 */
.sheet img.mart   { aspect-ratio: 16/9; object-fit: contain; background: #FBFAF6; } /* 寬版詳情 */
```

## 工程怎麼接

- `game/src/deck-ui.ts` 的 `memArtFiles` 會抓 `art/deck/memory/*.{svg,png,jpg,webp}`，再用檔名對 id。現在同一個 id 有 `.svg` 和 `.png` 兩個檔，**建議 glob 只抓 `.png`**，或是遇到同名時先用 png，這樣手機才不用每張即時跑 SVG 濾鏡。svg 留著給大圖或之後改圖用。
- 主色可以從 `manifest.json` 的 `cards[id].accent` 讀。例如選取時的光暈要用單張牌的顏色，就用這個值；不用的話，照 skin.css 用類別色 `--cat-*` 也可以，兩邊是同一個色系。
- 圖裡沒有字，牌名一樣由 UI 疊上去。

## 風格

- 跟 `art/ui/mobile-v12/skin.css` 一致：紙色 `#FBFAF6`、鉛筆線 `#33302B`、紙紋用同一種 feTurbulence 雜訊。
- 手繪感用兩層：描線和填色各自抖動，亂數不一樣，看起來像套色有點沒對準。整張主體歪 2–3 度，背景是蠟筆質感的不規則色塊。
- 每張有自己的主色，在類別色附近調色相和明暗：讀書偏藍、玩樂偏綠、運動偏紅橘、才藝偏紫、顧家偏金褐。同一類看得出是一家人，但每張都不一樣。
- 圖裡沒有任何文字、字母或數字。聯絡簿、考卷、剪報、借書卡上的「字」全部是波浪線。人物的臉一律空白，只畫頭髮。沒有商標，也沒有真人或有版權的角色。

## 比較難畫、做了取捨的牌

- **先寫功課**：卡通片頭不能畫真的卡通角色，所以改成舊電視播彩虹和音符，前面放只剩最後一格沒打勾的習作。
- **抽屜裡的卡牌**：避開任何真實卡牌遊戲，卡面只畫星星、圓、火焰、閃電。
- **電腦課**：螢幕一半是方塊小遊戲、一半是白色文件，用一道切線表示「一秒切回來」。方塊故意不排成任何真實遊戲的形狀。
- **私中入學考**、**登上國語日報**、**借書卡**：內容都要有字，所以全部用線條代替。報紙只留標題色條和一張小圖。
- **數學小老師**：不能寫數字，黑板上改畫三角形、圓和正方形，排隊同學的想法泡泡裡也是一個三角形。
- **過年的客廳**：「被問成績」畫不出來，就用茶壺、茶杯、一盤橘子和素面紅包（沒有福字）表現過年的客廳。
- **美術班術科**：「比桌子大的貓」畫成一張超出桌面的橘貓畫紙，貓的眼睛畫成閉著的線條。
