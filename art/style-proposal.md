# 美術風格提案 v0.1（MVP）

作者：美術設計｜狀態：提案，待 JadeLee 確認｜相關檔案：`art/theme.css`、`art/mockup-event-card.svg/.png`

## 1. 核心概念：「溫柔的畫面，刻薄的字」
專案包要求「可愛／簡樸畫面 vs 毒舌寫實文字的反差」。畫面就像一本被好好保存的家庭相簿和作業簿：柔軟、泛黃、帶有手作感。文字負責刺人，畫面負責抱住玩家。

**風格關鍵字**：底片相簿、作業簿橫線、聯絡簿紅筆、鐵窗花、紅磚牆、黑板與粉筆、泛黃膠帶、手繪線條、留白、平塗色塊（不寫實、不陰鬱）。

**插圖畫法**：粗細均勻的手繪褐色線 + 2～3 個平塗色塊 + 輕微紙紋。人物不畫五官細節（圓臉、點眼），讓玩家投射自己。每張插圖以「拍立得／底片相紙」外框呈現，與人生回顧相簿一致。

| 黑板綠 | `#2F4A3E` | 教室黑板 | 階段標題、年度開場 |
| 粉筆白 | `#EDEBE3` | 粉筆 | 黑板上的字 |
| 鐵窗藍灰 | `#4E6A73` | 鐵窗花 | 一般屬性條、框線 |
| 作業簿淡藍 | `#A9C4D9` | 橫線 | 卡片橫線紋、分隔線 |
| 膠帶黃 | `#E8D29B` | 泛黃膠帶 | 相簿膠帶、標籤 |

對比提醒：主要文字 `#3A3229` 在 `#FFFBF2` 上對比充足；`#716656` 對背景 4.75:1、對卡片 5.44:1，已達 AA。`--lock` 只用於停用狀態（WCAG 對停用元件不要求對比），鎖住原因的說明文字請用 `--accent` 或 `--muted`，不要用 `--lock`。

## 3. 字型（皆需支援繁中）
| 用途 | 字型 | 授權 | 備註 |
|---|---|---|---|
| 標題、結局、年度開場 | Noto Serif TC（思源宋體） | SIL Open Font License 1.1，可商用、可嵌入 | Google Fonts 可取得；有書卷／課本感 |
| 內文、選項、UI | Noto Sans TC（思源黑體） | SIL OFL 1.1 | 現有 CSS 已在用，延續 |
| 旁白、相簿手寫說明 | jf open 粉圓（justfont） | SIL OFL 1.1（依 justfont GitHub 說明，上 Steam 前建議再確認一次授權檔） | 圓潤可愛，最適合做「溫柔外表包毒舌」 |

不建議：系統內建的新細明體／微軟正黑體不能隨遊戲散布（僅作 fallback）。Steam 打包時字型檔要一併附上 OFL 授權文字。

## 4. UI 元件風格
- **事件卡**：作業簿紙（淡藍橫線＋左側紅色邊線），上方一張略微傾斜的拍立得插圖，角落貼一段膠帶。標題用宋體，內文黑體。圓角 6px（比現在的 12px 更像紙）。
- **按鈕／選項**：像作業簿上的勾選格，左邊一個方框 □，hover 時被紅筆打勾 ✓。主按鈕是黑板綠底＋粉筆白字。鎖住的選項用鉛筆虛線框＋灰字，鎖住原因用手寫字體（粉圓）寫在下面，像老師的批註。
- **屬性條**：成績單的格子風格，細框＋平塗填色；壓力條用紅磚紅，壓力 ≥ 70 時條上出現紅筆斜線。數值變化用紅筆「+3」「−5」小字跳出。
- **年度開場／階段總結**：整個畫面變成黑板，粉筆字寫年份（如「民國 81 年」），毒舌旁白用粉筆字；階段總結像「聯絡簿」一頁，有家長簽名欄（可做成彩蛋）。
- **人生回顧相簿**：米黃相簿頁、每頁 2～4 張拍立得、膠帶固定，`album.caption` 用粉圓手寫字寫在照片下方。最後一頁留一格空白相框給 22 歲以後。
- **圖騰（可重複使用）**：鐵窗花紋（做背景花紋與分隔線）、紅磚牆（結局畫面背景）、紅布條（榜單類事件）。
