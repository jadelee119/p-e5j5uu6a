# 回音牌插圖（美術設計）

v1.2 回音牌（`data/deck/cards_v12.json` 裡 `echo_card: true` 的 `e_<組名>_bitter`／`e_<組名>_warm`）的插圖。**每組一張，苦版和暖版共用**（跟時代牌一樣），所以畫面都是偏中性的日常場景：主物件明確，苦版的心酸和暖版的溫度都能疊上去，不畫任何一版專屬的情緒。

## 怎麼對應卡片

1. 卡片 id 去掉結尾的 `_bitter`／`_warm`，再去掉開頭的 `e_`，得到組名。例：`e_teenjob_warm` → `teenjob`。
2. 先找 `art/deck/echo/echo_<組名>.webp`（寬 480，遊戲用）。
3. 找不到就退回 `echo_<組名>.png`（600×750）。
4. 再找不到就用**實心缺圖樣式**（實心卡面、`--color-forced` 調淡的底色、卡名只出現一次、「強制」小標籤在卡名上方；詳情頁圖框改成淡紙紋，框裡不寫卡名）。

`manifest.json` 的 `groups[組名].cards` 也列了每張圖對應的兩張卡 id，可以直接查。

## 檔案

| 檔案 | 說明 |
|---|---|
| `echo_<組名>.webp` | 遊戲用，480×600，品質 82（每張約 15–25 KB） |
| `echo_<組名>.png` | 600×750，128 色調色盤 PNG（母版匯出、備援） |
| `src/echo_<組名>.svg` | 向量母版，480×600，含手繪抖線和紙紋濾鏡 |
| `manifest.json` | 組名 → id、主色、對應的兩張卡 id、webp／png／svg 路徑、一句畫面描述；另外記比例和安全區 |
| `contact-sheet.png` | 總覽，格子下面標組名和主色（開發用，字只出現在這張總覽上，不在圖裡；保留全彩，色票才準） |
| `src/gen_echo.py` | 產生器，每組的構圖都在這裡；要改圖請改這支，不要手改 SVG。會先檢查兩張卡 id 在 cards_v12.json 裡都存在 |
| `src/render_echo.mjs` | SVG → PNG（headless Chrome），再拼 contact sheet |
| `src/pack_echo.py` | 從全彩 PNG 輸出 WebP，再把 PNG 壓成 128 色調色盤（FASTOCTREE 不抖色；記憶牌用的 96 色 MEDIANCUT 會把小面積的黃色吃掉，例如檯燈） |
| `src/readme_table.py` | 從 manifest 更新下面的表格 |

重新產生：
```
cd art/deck/echo/src
python3 gen_echo.py
NODE_PATH=<裝了 puppeteer-core 的 node_modules> node render_echo.mjs
python3 pack_echo.py && python3 readme_table.py
```

## 規格（跟童年記憶牌 `art/deck/memory/` 一樣）

- **母版 4:5（480×600）**，匯出 PNG 600×750（1.25×）、WebP 480×600。
- **安全區：x 80–400、y 60–540**。重要的東西都在框裡，旁邊只放背景色塊和小裝飾。cover 裁成直的手牌圖窗、正方形相簿格都安全；比 4:3 更寬的框請用 `object-fit: contain`，空位補紙色 `#FBFAF6`。
- 筆觸直接 import `art/deck/memory/src/gen_memory.py` 的 helper（描線和填色兩層不同亂數的抖動、蠟筆質感色塊、紙紋），所以三批（記憶牌、時代牌、回音牌）是同一隻手畫的感覺。整張主體歪 2–3 度，不死板置中。
- **每組一個主色**，12 組互相明顯不同，也避開童年記憶牌 30 色和時代牌 11 色（用 CIELAB 色差檢查：跟既有 41 色的最小距離 ΔE 都 ≥ 18，12 色彼此 ≥ 30）。主色用在主物件和背景色塊（主色調淡 72%）。
- 圖裡沒有任何文字、字母或數字：名牌、招牌、斗方、紅包、文件、記帳本、便條都是空白或波浪線；銀行文件上的「章」只是空心紅圈。人物只出現手和背影，沒有臉。沒有商標、沒有真人、沒有版權角色。

## 取捨

- **teenjob**：苦版「封口封得很快」、暖版「教新人封口」都繞著封口機，所以主物件是封口機加圍裙。名牌空白，杯子沒有杯套圖案。
- **loan**：「對保」和「第一期」都在銀行，畫櫃檯、文件、印章、印泥。蓋章的地方只畫空心紅圈，不刻任何字。
- **single**：兩副碗筷講「兩個人的家」，不畫誰缺席。冰箱兩張便條對到暖版「一張寫給你，一張寫給大人」，苦版也不衝突。
- **cram**：「招牌換了」直接畫新招牌（空白、亮晶晶）和靠在牆邊的舊招牌，樓下停滿機車對到苦版的 line。教室裡的學生只有後腦勺。
- **care**：沒有畫長輩本人（避免畫成病弱的人），用輪椅、毛毯、藥盒代表照顧，相簿對到暖版「講你小時候的事」。
- **filial**：信封推來推去是暖版的「推了兩次」，旁邊的記帳本是苦版。兩隻手的袖子和膚色不同，看得出是兩代。
- **shop**：條紋遮雨棚呼應童年記憶牌 `mem_06_work_a`（同一家店長大了），角落小桌的作業對到苦版，櫃檯對到暖版的找錢。
- **newyear**：「被問現在在做什麼」畫不出來，跟記憶牌的過年一樣用客廳表現；紅包素面、斗方空白沒有福字。
- **child**：童年回音有五種版本（念書、玩、運動、才藝、顧家），所以畫「櫃子最上層打開的紙箱」，一次露出五樣東西：獎狀捲軸、直笛、接力棒、蠟筆、掛繩鑰匙。苦版的「櫃子最上層」、暖版的「最後一棒」「又上台了」都對得上。
- **track**：三條路線（普高、高職、五專）各有不同文字，畫成分三岔的路和三塊空白路牌；前景摺了一角的簡章對到苦版的 album_text。
- **branch**：苦版「報告寫到天亮」、暖版「沒蹺過的課」，畫天快亮的窗前書桌：筆電、報告、馬克杯。科大和出社會版本（回程公車、帶新人）沒有直接畫到，但書桌和天亮是三條路都會有的場景。
- **home**：「感冒那晚鑰匙轉了好幾下」「第一鍋湯」「留著的燈」三樣都畫進來：門上的鑰匙、一鍋蓋好的湯、亮著的檯燈。

## 手牌裁切焦點

手牌卡面框是 7:5，只看得到 4:5 圖的中間一段。`manifest.json` 每組多了 `hand_focus`（例如 `50% 62%`），手牌請用 `object-fit: cover; object-position: <hand_focus>;`。詳情頁照舊顯示整張圖。焦點數值在 `src/hand_focus.py`，改完重跑會更新 manifest 和 `hand-crop-preview.png`（預覽圖，不用打包）。
